# Ethan Kunz — Public Resume

Publicly accessible resume repository. Hosted via GitHub Pages.

**Live site:** [https://ee-edk.github.io/EDK-public-resume/](https://ee-edk.github.io/EDK-public-resume/)

## Repository Structure

- `index.html`: Primary resume (Embedded Systems & Electrical Engineering focus).
- `assets/`: Shared media assets (logos, videos).
- `archive/`: Superseded resume versions (read-only).

### Expert witness / IMS Legal materials

Added 2026-05-01 for an IMS Legal non-medical expert witness application:

- `EXPERT_BIO.md` — expert witness bio ("Senior Electrical Engineer | Technical Consultant | Expert Witness").
- `EXPERT_PACKET.html` — consolidated "Expert Witness Packet" (bio + rate sheet, print-optimized).
- `IMS_LEGAL_FORM_FIELDS.md` — ready-to-paste content for the IMS Legal expert profile application form.
- `RATE_SHEET.md` — consulting and expert witness fee schedule.
- `ims-legal-upload/` — the assembled upload package for the IMS Legal application (packet HTML, headshot, form-fields doc, its own README).

## Development

This repository is a static site. Changes to `index.html` are automatically reflected on the live site after pushing to `main`.

### Assets
All assets should be placed in the `assets/` directory.

### Archive
Historical snapshots are stored in `archive/` by year. Do not modify archived content.
